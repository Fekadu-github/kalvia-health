# Kalvia Health

- `frontend/` — React + Vite + TypeScript (`npm install && npm run dev`, set `VITE_API_URL`)
- `backend/` — FastAPI (`pip install -r backend/requirements.txt`, run `uvicorn backend.main:app` from this folder)

## Day-to-day shortcuts (frontend)

| Keys | Action |
|---|---|
| `Ctrl K` / `⌘ K` or `/` | Search cases, appointments, providers and screens |
| `G` then `P` / `C` / `A` | Providers / Cases / Appointments |
| `G` then `Y` (patient) / `M` (provider) | Payments / My profile |
| `G` then `O` / `N` / `R` (admin) | Overview / Create provider / Payment review |

The "Needs your attention" strip and the numbers on the menu refresh every minute and on every screen change.
